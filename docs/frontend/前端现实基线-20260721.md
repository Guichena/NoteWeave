# 前端现实基线（2026-07-21）

> L0 事实文档：以当前 `frontend/` 代码为准，校正过期阶段说明与审查报告中的前端描述。

## 1. 栈与入口

| 项 | 事实 |
| --- | --- |
| 栈 | React 19 + TypeScript 5 + Vite 5 + pnpm |
| 入口 | `main.tsx` → `AuthGate` → `App` |
| 路由库 | **无** React Router；`view` state + `history.pushState`（**无** `popstate`） |
| 脚本 | `pnpm dev` / `build` / `test` / `ui:check` |

## 2. 规模（约）

| 区域 | 规模 |
| --- | --- |
| `App.tsx` | ~375 行（壳 + lazy 四视图 + memo；业务/props 在 features） |

| `shared/*` | api（client/auth/error）、event-stream、util |

历史文档中「App 约 1.1 万 / 审查 ~4601 行」等数字 **已过时**。

## 3. 已抽出 vs 仍在 App

### 3.1 已落地（阶段 6 面板/API 向）

- Feature API/model/hooks：workspace、sources、conversations、answers、knowledge、memory、artifacts、research、executions  
- 展示组件：`ChatWorkbench`、`WikiWorkbench`、`MemoryReviewWorkbench`、`ResearchWorkbenchView`（lazy Sidebar/Report/Detail）、`ArtifactRail`（由 ChatWorkbench lazy）、`WorkspaceSettingsPanel`  
- 纯函数/审计 helpers：`artifact*`、`runStatus`、`researchReportDelivery` 等  
- Auth：`AuthGate`  

### 3.2 仍在 App（编排债）

- ~50+ `useState`，全局 `isBusy` / `status`  
- Workspace 会话恢复、上传、发问、Wiki mutation、Research launch/resume/export、Artifact job 全链路 handler  
- 巨型 props 袋传入 Research/Artifact（含 `any` / `@ts-nocheck` 边界）  
- 视图切换：`view: chat | wiki | memory | research` + 部分 `pushState`  

**结论**：功能面大体齐；「App 仅 provider/router/shell」**未**达成。面板抽出 **基本完成**，壳层生产化 **未**完成。

## 4. 视图与入口（当前）

| 视图 | 组件 | URL 习惯 |
| --- | --- | --- |
| chat | `ChatWorkbench` + 可选 ArtifactRail | `/`（backToChat） |
| research | `ResearchWorkbenchView` | `/research` |
| wiki | `WikiWorkbench` | wiki_url / 多处 pushState |
| memory | `MemoryReviewWorkbench` | `/memory/reviews` |

Chat 内：`routes.tsx` 三模式 `qa | note | wiki`；资料在 `source-drawer`；产物在右侧 lazy rail。

## 5. 测试与门禁

- Vitest：大量 api/store/纯函数单测；少量 DOM（如 `workspaceComponents.dom.test.tsx`）  
- **几乎无** E2E / Playwright（v1 有 smoke，v2 未对齐）  
- `ui:check`：禁止阶段宣传文案；要求三模式 routes；要求资料区/Artifact lazy/Note 入库/Wiki 入口等 **与当前文件位置一致**（PR0 已按 ChatWorkbench 修正，勿再假定 App 内 Artifact lazy）
