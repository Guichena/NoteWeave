# 前端重构说明：工作台 → 多对话布局与设计系统

> 第一版参考 NotebookLM 做了“来源 | 对话 | 产物”三栏；第二版回到 NoteWeave 自己的产品模型——**一个工作台（资料库）下有多个对话**，并按“功能齐全、界面精简”的原则重做了 Wiki、记忆等页面。

## 1. 信息架构

```text
┌ 侧边栏 ─────────────┬ 主区（白色画布）─────────────────────────────┐
│ NoteWeave       [«] │ 对话标题              [来源 6 | 产物]        │
│ ┌ 工作台 ▾ ───────┐ │                                  ┌ 右侧面板 ┐ │
│ │ 6 份资料·3 个对话│ │   消息流（居中 760px）            │ 来源勾选 │ │
│ └────────────────┘ │                                  │ 或 产物  │ │
│ ✎ 新对话            │                                  └─────────┘ │
│ 资料库 / 深度研究    │   ┌ 输入框：问法 · 范围 · 发送 ┐                │
│ 知识库 / 记忆        │                                              │
│ 对话                 │                                              │
│  · 注意力机制复习    │                                              │
│  · 期末考点整理      │                                              │
│ 账户 ▴               │                                              │
└─────────────────────┴──────────────────────────────────────────────┘
```

- **工作台 = 资料库**：侧边栏顶部的工作台卡片显示资料数与对话数；切换工作台即切换资料库。
- **对话是一等公民**：侧边栏列出该工作台下的全部对话，“新对话”固定在上方。所有对话共享同一批来源。
- **来源 / 产物**：放进对话页右侧同一个面板，用页头的分段按钮切换；≥1200px 默认展开，更窄时作为抽屉覆盖。
- **侧边栏可收起**为 64px 图标栏（偏好存在 localStorage）；手机端为抽屉。
- 账户菜单收纳：工作台设置、新建工作台、明暗主题、退出。

## 2. 各页面

| 页面 | 结构 | 精简掉的内容 |
| --- | --- | --- |
| 对话 | 消息流 + 右侧面板；回答里的 `[n]` 是可点击角标，底部一个“来源引用”折叠 | 模式说明条、知识路径图、默认展开的四张卡片 |
| 知识库（Wiki） | 目录（搜索、类型、分组）｜ 阅读区。总览 = 4 个数字 + 知识图谱 + 最近更新 + 需要处理；页面 = 文档 + 关系栏（局部图谱、出链/反链） | 维护类功能（重建链接、自动补缺、问题队列、手动补页、任务、日志）全部收进“管理”抽屉；页面字段罗列改为文档式阅读，`[[链接]]` 可点击 |
| 资料库 | 标题 + 4 个数字 + 来源列表 ｜ 上传 | 与侧边栏重复的“当前工作台”卡片 |
| 深度研究 | 左侧问题与设置（浅底）｜ 右侧报告 | 历史卡片的审计字段只在选中时展开 |
| 记忆 | 审核队列 ｜ 审核详情；空状态为一行三步流程 | 第三栏“运行时生效”改为底部三条规则 |

## 3. 样式架构

唯一入口 `src/styles/index.css`：

```
tokens.css    颜色 / 字号 / 圆角 / 阴影；深色主题只重定义颜色
base.css      reset、按钮、表单、chip、卡片、markdown、骨架屏、动画
shell.css     侧边栏、工作台切换、账户菜单、主区画布、设置侧板
dialogs.css   新建工作台 / 会话、工作台设置
chat.css      对话页、来源面板、消息、输入框
studio.css    产物目录、运行记录、生成表单、思维导图
library.css / research.css / wiki.css / memory.css / auth.css
```

约定：组件只读 token；主操作深色实心（`.primary-action`），次操作 `.secondary-button`，图标按钮 `.icon-button`；唯一强调色 `--accent` 只用于选中、焦点、链接与引用角标；大标题用衬线 `--font-display`。

## 4. 测试与脚本

- DOM 测试按新结构改写：Shell（侧边栏、账户菜单）、Chat（右侧面板切换、来源勾选）、ChatSourcesPane、Memory、Wiki 关系栏。
- `ui:check` 要求 `app-sidebar`、`sidebar-conversation`、`studio-pane`、来源勾选接入 QA 范围与单一样式入口。
- Playwright 真实环境用例同步了选择器与新的尺寸阈值。
