# 前端重构说明：笔记本三栏与设计系统

> 落地 [NotebookLM 风格对照与改版建议](./NotebookLM风格对照与改版建议.md) 的 P0 + 大部分 P1，并统一全站视觉。

## 1. 结构变化

| 区域 | 之前 | 现在 |
| --- | --- | --- |
| 外壳 | 196px 左侧 rail：品牌、五个入口、工作台、会话列表、设置、主题、退出 | 56px 顶栏：品牌 / 工作台 ▾ / 会话 ▾ ＋ 分段导航 ＋ 状态、主题、账户菜单 |
| 会话 | 全局 rail 里的一级列表 | 顶栏面包屑里的次级切换（`ConversationSwitcher`），移动端在导航抽屉里 |
| 来源（左栏） | 三格统计 + 最近 4 条 + “打开资料库” | 完整来源列表，勾选即 QA 范围（`selectedQaSourceIds`），栏内上传 / 拖放 |
| 对话（中栏） | 模式说明条、知识路径图、范围 `details` | 干净的对话流；输入框内含问法下拉、范围摘要、发送 |
| 产物（右栏） | 全屏 portal modal | 常驻 `aside.studio-pane`；<1280px 为右侧抽屉，<900px 来源也变为抽屉 |

| Wiki 页面 | 字段堆叠 | 文档式阅读：标题、元信息、Markdown 正文、引用、出链/反链、版本 |

## 2. 样式架构

`src/styles.css` 与 `src/styles/visual-refresh.css`（合计约 1.6 万行、互相覆盖）已删除，改为唯一入口 `src/styles/index.css`：

```
tokens.css    颜色 / 字号 / 圆角 / 阴影；深色主题只重定义颜色
base.css      reset、按钮、表单、chip、卡片、markdown、骨架屏等通用原语
shell.css     顶栏、导航、弹出层、设置侧板
dialogs.css   新建工作台 / 会话、工作台设置
notebook.css  来源 | 对话 | 产物 三栏与响应式
studio.css    产物目录、运行记录、生成表单、思维导图
library.css / research.css / wiki.css / memory.css / auth.css
```

约定：

- 组件只读 token（`--surface`、`--ink`、`--accent`…），不写字面色值。
- 主操作 = 深色实心（`.primary-action` / 无 class 的 `<button>`），次操作 = `.secondary-button`，图标按钮 = `.icon-button`。
- 唯一强调色 `--accent` 只用于选中、焦点、链接、引用角标。
- 大标题使用 `--font-display`（衬线），正文与控件使用 `--font-ui`。

## 3. 测试与脚本

- `ChatWorkbenchContext`、`ChatSourcesPane`、`WorkbenchShell` 的 DOM 测试已按新结构改写（三栏同时存在、产物不是 modal、来源可勾选）。
- `ui:check` 改为要求：顶栏 `app-nav`、`ConversationSwitcher`、`studio-pane`、来源勾选接入 QA 范围、单一样式入口；禁止 `createPortal`（Chat）、`mode-context-line` 与 `visual-refresh.css`。
- Playwright 真实环境用例同步了选择器；`visual-contract.spec.ts` 的尺寸阈值按新设计（控件 30–36px、辅助字 ≥11px）调整。
