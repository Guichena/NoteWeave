# Personal Research Override

本页覆盖 `MASTER.md`。

## 1. Page Intent

个人研究区要体现“积累中的知识项目”，不是普通资源列表。

用户应该在这里明确看到：

- 当前研究主题
- Source 沉淀进度
- Card 结构化程度
- 可继续生成什么 Artifact

## 2. Layout

项目列表页：

```text
Header
Project Summary Metrics
Project Cards / Table
```

项目详情页：

```text
Project Header
Project Health Strip
Tabs: Sources / Cards / Generate / Artifacts / Methodology
Active Tab Content
```

## 3. Tab Guidance

- `Sources`：导入、状态、重试
- `Cards`：Article / Concept / Synthesis 分区，强调证据链接
- `Generate`：目标导向表单，不做长配置页
- `Artifacts`：展示与项目关联的产物
- `Methodology`：少量但高价值，强调模板感

## 4. Visual Rules

- 项目标题可使用 serif heading，强调“研究主题”
- 卡片视图要区分 Article Card 与 Concept Card 的语义
- Synthesis Card 应比普通 Card 更沉稳、更像结论

## 5. Avoid

- 不要把所有卡片混在一个瀑布流里
- 不要把 methodology 做成复杂流程图编辑器
- 不要让 Generate 表单比最终产物更重
