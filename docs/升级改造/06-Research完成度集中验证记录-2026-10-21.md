## 3. 新增集成场景

`ResearchCompletionRuntimeIntegrationTest` 使用真实 Spring 事务、任务服务和 HTTP 过滤器，验证：

- 生成中断后跨租约保留模型授权消耗，旧租约不可继续授权，取消只释放剩余预算。
- 两个并发请求重放同一序号，数据库只保存一份调用授权。
- 内部请求缺少身份凭证、快照摘要篡改均被拒绝，正确请求才产生授权。
- 需求查询受工作台与 Run 的范围约束。
- 清理只删除旧租约片段，保护当前活动租约；Run 结束前保留调用消耗元数据，终态后按保留期删除。

MySQL 锁矩阵复用 `ResearchAgentMySqlLockMatrixIT`，使用独立的普通应用账号与 root 控制连接，观察真实数据库锁等待关系。12 个测试方法覆盖 13 个锁顺序场景；结果以最终证据文件为准。

最终证据全部为 `VERIFIED`，包括协调器先于取消和取消先于协调器。最后一轮直接编译当前锁测试源码，再通过 Surefire 执行全部 12 个方法；没有修改断言、跳过场景或用模拟锁替代 MySQL。新版运行集成的五个场景也分别通过 H2 与 MySQL 检查。

### 6.3 真实运行发现的日期误判与修复

新增 `ResearchSourceDateGrounding`，只解析无歧义的完整年月日并核对日期值，支持年在前的数字日期、中文日期、英文月份日期。仍要求完整 `date_quote` 逐字存在于当前事实绑定的服务端归档；保留截止日期、产品、分支和时间适用性校验，不猜测日月顺序。Worker 提示同步区分规范化的 `date` 与保持原格式的 `date_quote`。
