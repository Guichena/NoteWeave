# 系统改造计划：对齐简历五项能力

日期：2026-10-23。基线 `70631bd0`，集成分支 `codex/oth-20261023`（`e524721e`）。本文件只做计划，不改代码。

## 0. 结论

五项能力在代码里都已经落地，不需要从零建设。真正缺的是三处模块接缝、一处真实缺陷簇，以及一套能复跑的验收。16 项任务里大部分已经完成，剩下两项的范围要缩小。

改造重点按优先级：

1. 出队幂等收口，让异步流水线的幂等承诺成立。
2. 产物编辑回流记忆，补上能力四与能力五之间的接缝。
3. Note/Wiki 契约失败定性，这是能力二的真实缺口。
4. 五项能力各留一个可复跑场景，替代全矩阵浏览器验收。

## 3. 改造设计

### 3.1 出队幂等收口（能力三）

现状：14 处直接插入 `task_outbox`，没有业务唯一键；单行投递 token 只保证至少一次投递，不保证入队不重复。

设计：

- 新增 `TaskOutboxEnqueuer`，在调用方事务内按 `(task_id, topic, message_key)` 查 READY 或 PROCESSING 的在途行。
- 相同载荷返回既有行 id，不同载荷抛冲突，不存在则插入。
- 只改造已经持有 source 或 snapshot 行锁的四个点：上传到解析、解析到切片、切片到向量、向量到索引。并发安全依赖既有行锁，不新增迁移。
- 其余 10 处保持现状，在文档里记为未覆盖，不假装全局幂等。

验收：同键两个事务只产生一行；同键不同载荷被拒绝；SENT 与 DEAD_LETTER 之后允许重新入队。

### 3.2 产物编辑回流记忆（能力四与能力五的接缝）

现状：产物版本保存与回滚不产生记忆信号，产物与长期记忆之间只有只读的版本校验。

设计：

- 产物版本保存或回滚时，把编辑差异映射为记忆候选，不直接晋升。
- 候选的 `source_ref` 用产物版本 id，复用 V193 收据语义保证一次编辑只处理一次。
- 是否晋升交给既有候选门控，避免产物编辑污染长期记忆。
- 范围：新增一个发布类，在版本保存与回滚两处调用。

验收：编辑一次只产生一条候选；重复保存不重复；回滚产生反向候选；候选未晋升前不影响回答。

### 3.3 Note/Wiki 契约失败定性（能力二）

现状：11 个 `Phase3NoteWikiContractTest` 用例在基线就失败，断言期望回答里出现 `source-window-missing` 等标记，实际没有。标记本身仍在 `NoteRecallRetriever` 里生成。

设计：

- 先定性：是渲染链路把标记丢了，还是测试固化了已经废弃的文案。
- 若是渲染问题，修 Note 答案装配与提示词渲染，Wiki 同理。
- 若是文案废弃，改断言并在文档里写明原因。
- 不允许直接删除断言了事。

验收：11 个用例转绿，或逐条给出原因与替代断言。

### 3.4 本地资料可读性（能力二边界）

现状：无 ES 的资料落成 PARSED/DISABLED/NOT_PROJECTED，检索路径只认 INDEXED，生产 guard 又禁止开启本地回退。

建议：关闭这项改造。在文档与前端文案里明确本地资料只读、不参与检索。将来若要做，只做 QA 单模式最小版，不动 Note。

## 4. 分期

第一期，可靠性与真实缺陷，工作量小：

- OTH-11 三态收尾。
- 3.1 出队幂等，四个点。
- 3.3 Note/Wiki 定性。
- 跑一次全量回归，与基线对比。

第二期，能力接缝，工作量中：

- 3.2 产物编辑回流记忆。
- 3.4 文档与前端文案。
- OTH-16 对这两处做独立复审。

第三期，可复跑验收，工作量中：

- 能力一：固定资料加桩模型的完整研究回放，含一次断点恢复。
- 能力二：同一问题在 QA、Note、Wiki 三条链路的结果对比。
- 能力三：流水线故障注入，租约过期接管与预算耗尽各一次。
- 能力四：报告与视频两类产物生成，含一次版本回滚。
- 能力五：候选到晋升，含一次冲突拒绝。

## 5. 明确不做

- V195 全量唯一键与 14 点统一改造。
- OTH-12 的十三文件本地读取闭环。
- OTH-15 的全矩阵浏览器验收与付费模型调用。
- research 内部逻辑改动。

## 6. 验收与度量

- 每期结束跑改动包测试与全量测试，失败项与基线逐条对比。
- 五项能力各留一条可复跑命令，写清前置数据与桩。
- 简历里的数字不写死，只记录测量口径：输入 Token 统计来源、关键事实检查的判定方式、研究单元完成率的统计口径。

## 7. 风险

- Note/Wiki 失败原因未定，定性后可能牵出比预期更大的范围。
- V193 与 V194 迁移尚未应用，真正部署前需要演练与回滚方案。
- 产物回流记忆若绕过候选门控会污染长期记忆，必须保持候选语义。
- 出队幂等只在持有行锁的路径成立，其余路径要如实记录为未覆盖。
