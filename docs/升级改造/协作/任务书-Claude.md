| 编号 | 内容 |

| E1 | `experiments/deep-research/`：约 20 条真实研究问题，单次 LLM 评分规则（事实准确、引用准确、完整性、来源质量、工具效率，0 到 1 分加通过与否），有效单元格完成率的统计口径 |

| E5 | `experiments/pipeline/`：格式覆盖、大文件耗时与内存、增量复用比例、PDF 抽取编辑距离 |
