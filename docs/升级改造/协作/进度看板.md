### 3A 查询改写（2026-10-12）

- 没有新增 HTTP 路径。回答详情和 `GET /answer-runs/{runId}/evidence` 增加 `retrieval_rewrite`：`is_standalone`、`standalone_query`、`keyword_query`、`method`（`LLM` 或 `RULE`）、`degradation_reasons`。计划里没有改写字段时响应省略该字段。`evidence_sufficiency` 本阶段不返回。
- 后端内部接口 `com.noteweave.retrieval.qa.ScopedPassageSearch` 已有实现，类名 `com.noteweave.chat.HybridScopedPassageSearch`。
- 新增配置 `noteweave.retrieval.query-rewrite.enabled`，环境变量 `NOTEWEAVE_QUERY_REWRITE_ENABLED`，默认 true。`docker-compose.yml` 同步了这个变量。
- 没有数据库迁移，没有新增表列。
- 没有删除检索实现。`QaQueryExpansionService` 仍保留，只在改写不可用（包括首轮规则改写）且召回不足时使用。对话拼接文本不再作为 `AnswerContext.query()`。
- 还没验证的部分：没有用真实模型跑过改写。测试环境关闭了 LLM，追问走规则降级，关键词查询是当前问题加上话题锚点。
