# NoteWeave v2 名词口径与汇报词表

## 1. 用途

这份文档用于统一 NoteWeave v2 在架构设计、产品汇报、简历表达和后续开发中的核心名词，避免同一概念在不同文档里出现多套说法。

原则：

- 对外汇报优先用中文主名词，必要时补英文别名
- 产品名、能力名、技术模块名分开表达
- 同一个对象只保留一套正式术语

## 2. 核心名词

### 2.1 产品层

- `问答模式`
  对外主口径。英文可补 `Ask Mode`。

- `Wiki 模式`
  对外主口径。历史文档中的 `Full Wiki` 统一收敛到这里；如需强调全量知识组织能力，可写成 `Wiki 模式（Full Wiki）`。

- `资料调查模式`
  对外主口径。英文可补 `Investigation Mode`。

- `深度研究`
  产品入口名。英文可补 `Deep Research`。

- `右侧产物栏`
  产品入口名。英文别名 `Artifact Actions Rail`。对外不优先使用“按钮栏”“动作栏”等多个叫法。

## 3. 能力层

- `Deep Research 智能体`
  用于项目亮点、面试和架构讲解。

- `Deep Research Engine`
  用于技术架构中描述后端执行引擎，不直接作为产品名。

- `Evidence-Gated Branchable Research Harness`
  用于深度研究能力升级后的亮点和架构表述，强调深度研究不是一次性生成，而是带证据门控、分支探索和恢复能力的研究执行系统。

- `Table-as-State`
  用于深度研究详细讲解，表示 `Research Table` 不只是结果展示表，也是执行状态层。

- `Stop Contract`
  用于深度研究详细讲解，表示研究 run 从开始就显式声明完成条件、部分完成条件和停止条件。

- `Premature Commitment Guard`
  用于深度研究详细讲解，表示系统避免过早锁死到单一路径或单一来源的保护机制。

- `受控式产物生成 Agent`
  用于项目亮点和能力描述，表示右侧产物栏背后的生成能力。

- `Artifact Runtime`
  用于技术架构中描述受控式产物生成的执行平面，不直接替代产品名。

- `Production Action`
  正式术语，表示“报告生成”“测验生成”“FAQ 生成”等统一产物动作抽象。

- `Schema-Gated Skill Graph Runtime`
  用于产物生成能力升级后的亮点和架构表述，强调执行前先形成结构化计划，再按技能子图和能力策略受控执行。

- `Style Profile`
  用于产物生成详细讲解，表示用户可配置的写作风格、结构偏好、篇幅和受众约束。

- `Skill Graph`
  用于产物生成详细讲解，表示 Skill 不再只是平铺列表，而是可展开的技能子图。

- `Capability Union Policy`
  用于产物生成详细讲解，表示用户自定义 MCP 时，对能力组合风险做统一权限判断的策略层。

## 4. 记忆层

- `记忆晋升机制（Graduated Memory）`
  对外主口径，强调长期知识不是直接堆积聊天历史，而是经过门控晋升。

- `上下文信号（Context Signal）`
  正式术语，表示来自会话、研究轨迹、反馈等的弱信号。

- `记忆候选（Memory Candidate）`
  正式术语，表示待判断、待晋升的记忆对象。

- `长期记忆对象（Memory Object）`
  正式术语，表示通过门控晋升后进入长期复用层的记忆对象。

- `新颖性门控（Novelty Gate）`
  正式术语，表示是否值得写入长期记忆的第一道门。

- `任务邻域验证（Task Neighborhood Validation）`
  正式术语，表示候选内容是否能在相邻任务簇中复用的第二道门。

## 5. 推荐替换

- `Full Wiki` -> `Wiki 模式`
- `右侧产物按钮栏` / `右侧产物动作栏` -> `右侧产物栏`
- `长期 Memory` -> `长期记忆`
- `Promoted Memory` -> `长期记忆对象（Memory Object）`
- `Artifact Memory` -> `记忆候选` 或 `已确认产物形成的稳定记忆来源`

## 6. 一句话总口径

`NoteWeave v2 是一个参考 NotebookLM 形态的统一知识工作台：以问答模式、Wiki 模式和资料调查模式承接日常知识工作，以深度研究和右侧产物栏承接重型智能任务，并通过记忆晋升机制把高价值上下文与已确认产物沉淀为可长期复用的知识。`
