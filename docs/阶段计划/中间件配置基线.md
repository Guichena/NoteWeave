# NoteWeave v2 中间件配置基线

## 1. 目的

这份文档冻结后续开发时的中间件配置口径，避免后面一边写代码一边改服务名、端口、topic、bucket 和 index。

它回答五个问题：

1. 本地 `docker compose` 应该起哪些服务
2. 每个中间件的最小配置是什么
3. Java / Python / 前端 各自该读哪些环境变量
4. topic / bucket / index / key 的命名怎么统一
5. 哪些配置现在就应该冻结，哪些可以后面再细化

## 2. Docker Compose 基线

建议服务名统一如下：

1. `mysql`
2. `redis`
3. `kafka`
4. `minio`
5. `elasticsearch`

建议本地端口：

1. `mysql: 3306`
2. `redis: 6379`
3. `kafka: 9092`
4. `minio api: 9000`
5. `minio console: 9001`
6. `elasticsearch: 9200`

## 3. MySQL 基线

### 3.1 数据库名

- `noteweave`

### 3.2 本地账号

- username：`noteweave`
- password：`noteweave123`
- root password：`root123`

### 3.3 Java 配置项

- `SPRING_DATASOURCE_URL=jdbc:mysql://localhost:3306/noteweave?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai`
- `SPRING_DATASOURCE_USERNAME=noteweave`
- `SPRING_DATASOURCE_PASSWORD=noteweave123`
- `SPRING_FLYWAY_ENABLED=true`

### 3.4 Hikari 建议

- `maximumPoolSize=16`
- `minimumIdle=4`
- `connectionTimeout=3000`
- `idleTimeout=600000`

### 3.5 Flyway 规则

1. 只允许 Flyway 改表
2. migration 放在 `backend/src/main/resources/db/migration`
3. 当前第一批必须落：
   `V001` 到 `V006`

## 4. Redis 基线

### 4.1 用途

1. 登录态缓存
2. 幂等键
3. SSE / WebSocket 短期运行态
4. 任务短期进度缓存

### 4.2 Java 配置项

- `SPRING_DATA_REDIS_HOST=localhost`
- `SPRING_DATA_REDIS_PORT=6379`

### 4.3 Key 命名建议

- `idempotency:chat:{requestId}`
- `stream:chat:{assistantRequestId}`
- `stream:task:{taskId}`
- `session:user:{userId}`

### 4.4 过期时间建议

- 幂等键：`15m`
- 聊天流状态：`30m`
- 任务流状态：`24h`

## 5. Kafka 基线

### 5.1 模式

- `Kafka 4.x`
- `KRaft-only`

### 5.2 Topic 命名

第一批冻结：

1. `noteweave.source.parse`
2. `noteweave.source.index`
3. `noteweave.research.run`
4. `noteweave.artifact.job`
5. `noteweave.memory.promote`

### 5.3 Topic 配置建议

开发环境建议：

1. `partitions=3`
2. `replication.factor=1`
3. `retention.ms=604800000`

### 5.4 Consumer Group 命名

1. `noteweave-source-worker`
2. `noteweave-research-worker`
3. `noteweave-artifact-worker`
4. `noteweave-memory-worker`

### 5.5 Java 配置项

- `SPRING_KAFKA_BOOTSTRAP_SERVERS=localhost:9092`
- `SPRING_KAFKA_CONSUMER_ENABLE_AUTO_COMMIT=false`
- `SPRING_KAFKA_LISTENER_ACK_MODE=manual`

### 5.6 Python Worker 配置项

- `KAFKA_BOOTSTRAP_SERVERS=localhost:9092`
- `KAFKA_RESEARCH_TOPIC=noteweave.research.run`
- `KAFKA_ARTIFACT_TOPIC=noteweave.artifact.job`

### 5.7 投递规则

1. 业务事务先写 `task + task_outbox`
2. publisher 再投 Kafka
3. consumer 成功后才 ack
4. 失败任务走重试或回写失败状态

## 6. MinIO 基线

### 6.1 Bucket

第一批冻结：

1. `noteweave-source`
2. `noteweave-derived`
3. `noteweave-export`

### 6.2 本地账号

- access key：`minioadmin`
- secret key：`minioadmin`

### 6.3 Java / Python 配置项

- `MINIO_ENDPOINT=http://localhost:9000`
- `MINIO_ACCESS_KEY=minioadmin`
- `MINIO_SECRET_KEY=minioadmin`

### 6.4 Object Key 规则

原始文件：

- `workspace/{workspaceId}/source/{sourceId}/snapshot/{versionNo}/original/{fileName}`

解析正文：

- `workspace/{workspaceId}/source/{sourceId}/snapshot/{versionNo}/parsed/content.md`

结构元数据：

- `workspace/{workspaceId}/source/{sourceId}/snapshot/{versionNo}/parsed/structure.json`

Artifact 导出：

- `workspace/{workspaceId}/artifact/{artifactId}/version/{versionNo}/export/{format}/{fileName}`

Research 快照：

- `workspace/{workspaceId}/research/{researchRunId}/snapshot/{checkpointId}.json`

## 7. Elasticsearch 基线

### 7.1 第一批索引

1. `nw-source-chunk-v1`
2. `nw-knowledge-v1`
3. `nw-artifact-v1`
4. `nw-memory-v1`

### 7.2 Alias 建议

1. `nw-source-chunk`
2. `nw-knowledge`
3. `nw-artifact`
4. `nw-memory`

### 7.3 Source Chunk 索引字段建议

1. `workspace_id`
2. `source_id`
3. `source_snapshot_id`
4. `chunk_id`
5. `title`
6. `content`
7. `section_path`
8. `page_no`
9. `metadata`
10. `created_at`

### 7.4 Java 配置项

- `ELASTICSEARCH_URIS=http://localhost:9200`

### 7.5 检索规则

1. 第一批默认先跑 BM25 + metadata filter
2. dense vector 作为增强，不作为第一批阻塞项
3. 所有查询必须带 `workspace_id`

## 8. 前端流式基线

### 8.1 聊天流

- `GET /api/v2/chat/requests/{assistantRequestId}/stream`
- 协议：`SSE`

事件：

1. `chat.delta`
2. `chat.citation`
3. `chat.completed`
4. `chat.failed`

### 8.2 任务流

- `GET /api/v2/tasks/{taskId}/events`
- 协议：`SSE`

事件：

1. `task.status`
2. `task.progress`
3. `task.completed`
4. `task.failed`
