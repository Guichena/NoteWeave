# NoteWeave v2 函数级开发清单

## 1. 目的

这份文档把阶段计划继续下钻到“类 / 函数 / 测试点”这一层。

它不是最终代码，而是后续 AI 开发时的函数级施工图。

使用方式：

1. 先确定当前要做哪个子阶段
2. 只读取该子阶段对应函数清单
3. 先为这些函数写测试
4. 再按函数顺序补实现

## 2. 命名约定

### 2.1 Java 主系统

推荐目录：

`backend/src/main/java/com/noteweave/...`

推荐分层：

- `controller`
- `application`
- `domain`
- `infrastructure`
- `repository`
- `model`
- `dto`

推荐命名：

- Controller：`XxxController`
- 应用编排：`XxxApplicationService` 或 `XxxOrchestrator`
- 领域服务：`XxxDomainService`
- 基础设施：`XxxStorageService / XxxPublisher / XxxIndexer`

### 2.2 Python Worker

推荐目录：

- `app/api`
- `app/runner`
- `app/tools`
- `app/store`
- `app/models`

推荐命名：

- runner：`run_xxx_task`
- tool：`search_web / read_source / verify_cell`
- store：`load_task_input / report_progress / submit_result`

### 2.3 前端

推荐目录：

`frontend/src/features/...`

推荐命名：

- 页面：`XxxPage.tsx`
- 面板：`XxxPanel.tsx`
- hooks：`useXxx.ts`
- api：`xxxApi.ts`
- store：`useXxxStore.ts`

## 8. 最后说明

后续 AI 开发不要把这份文档当成“必须一次写完的清单”，而应该按下面方式使用：

1. 每次只取当前子阶段对应函数
2. 先找旧代码可迁移点
3. 先把测试写出来
4. 再按这份函数顺序补实现
