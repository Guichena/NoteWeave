# 项目亮点与简历草案

## 1. 核心项目亮点

这版简历叙事建议优先突出两个最核心的技术抓手：

1. 基于 TAS 思路的 Deep Research 智能体
2. 受控式产物生成 Agent

在此基础上，再补充产品形态、Wiki 知识编织和证据沉淀能力。

### 亮点 1：基于 TAS 的 Deep Research 智能体

设计 Deep Research 智能体，核心借鉴 `Table-as-Search` 思路，将开放式研究问题转化为动态表格补全任务；通过 `Research Plan -> Research Table -> Search -> Read -> Extract -> Verify -> Report` 的受控循环，把研究过程从一次性生成升级为可追踪、可验证、可沉淀的长任务系统。

这部分最值得强调的关键词：

- Table-as-Search
- Loop Engineering
- Goal-conditioned Reading
- Cell-level Evidence Verification
- Research Trace

### 亮点 2：受控式异步产物生成 Agent

设计面向报告、测验、学习指南、FAQ、Wiki 草稿、视频总结等场景的产物生成 Agent，采用 `Production Action + Prompt Recipe + Artifact Runtime` 的统一主链路，把不同类型的生成任务抽象为可配置 Action，而不是为每个功能单独写一套硬编码流程。

这部分最值得强调的关键词：

- Controlled Agentic Graph Harness
- Production Action
- Prompt Recipe
- Artifact Job / Artifact Version
- Verifier / Repair

### 亮点 3：NotebookLM 风格的知识工作台产品形态

参考 NotebookLM 的产品交互，将系统设计为三栏式知识工作台：左侧资料与主题范围，中间主阅读 / 对话区，右侧产物按钮栏与结果区；用户可以在同一上下文里直接发起问答、资料调查、Deep Research 和产物生成，而不需要频繁切换产品世界。

### 亮点 4：Full Wiki 知识编织体系

设计 `Full Wiki` 系统，将知识视为由页面、链接、反向链接、引用、关系和缺口分析组成的长期维护网络，而不是扁平笔记列表；使调查结果、研究报告和阶段性理解都可以进一步沉淀为稳定知识页。

### 亮点 5：Agent / Skill / MCP 驱动的证据优先知识闭环

将 Source、Citation、Artifact Version 与 Research Trace 统一为共享证据层，并通过 Agent、Skill、MCP 组成的能力栈驱动复杂研究与生成任务，使结果能够显式回写为 Note、Wiki 草稿、Investigation Note 或 Artifact，而不是停留在一次性回答。

## 2. 简历长版表述

主导新一代 AI 知识工作台的架构设计，重点实现两个核心能力方向：一是基于 Table-as-Search 思路设计 Deep Research 智能体，将开放式研究问题建模为带外部表格状态、证据绑定、字段级验证和执行轨迹的长任务系统；二是设计受控式异步产物生成 Agent，将报告、测验、学习指南、FAQ、Wiki 草稿和音视频总结等能力统一抽象为 Production Action，并通过 Artifact Runtime、Prompt Recipe、Verifier / Repair 和版本化 Artifact 提交链路完成受控生成。在产品层面，系统参考 NotebookLM 的知识工作台形态，将问答、Wiki、资料调查、Deep Research 按钮和右侧产物按钮栏收拢到单一用户工作区内，并通过 Source、Citation、Research Trace 与 Artifact Version 形成证据优先的知识沉淀闭环。

## 3. 简历中版表述

设计统一的 AI 知识工作台，核心包含两条技术主线：基于 TAS 的 Deep Research 智能体，以及受控式异步产物生成 Agent。前者将研究任务表格化并通过 Search、Read、Extract、Verify 的循环完成证据驱动研究；后者将报告、测验、学习指南等产物抽象为 Production Action，通过统一 Artifact Runtime 执行。系统同时采用 NotebookLM 风格三栏形态，并用 Agent / Skill / MCP 能力栈与共享证据层支撑结果回写和知识沉淀。

## 4. 简历短版表述

设计 AI 知识工作台，重点实现基于 Table-as-Search 的 Deep Research 智能体与受控式产物生成 Agent，并以 NotebookLM 风格工作台和证据优先回写链路完成知识沉淀闭环。

## 5. 面试安全表述

建议优先使用以下措辞：

- `designed`
- `defined`
- `built MVP of`
- `implemented prototype for`
- `modeled as`
- `rebuilt around`

在实际实现完成前，建议避免使用以下表述：

- `fully productionized`
- `completed autonomous research system`
- `already replaced the old system in production`
- `delivers stable enterprise-grade collaboration`

## 6. 面向原型交付的目标

第一版原型至少要足以支撑下面这句描述，并且能够真实成立：

`Built a prototype of an AI knowledge workbench centered on a TAS-based Deep Research agent and a controlled artifact-generation agent, with evidence-backed writeback into notes, wiki drafts, investigation records, and versioned artifacts.`
