## 2. Correlation 日志验收

请求携带：

```text
X-Correlation-ID: docker-correlation-check
```

运行态结果：

- HTTP 状态：`200`；
- `X-Correlation-ID` 原样返回；
- `X-Request-ID` 与响应体 `request_id` 一致；
- Backend 日志包含 `request_id`、`correlation_id`、`user_id`、`workspace_id`、`task_id`、`source_id`、`event_id`；
- Kafka、Outbox、Elasticsearch 后台链路使用事件或 topic-partition-offset 填充 event/correlation 上下文。

## 3. 适用边界

本结果只适用于当前机器、Docker 资源、数据量和并发条件。CI 必须在固定 runner、固定 fixture 和独立 Compose project 下重新建立阈值，不能直接继承本机绝对数值。
