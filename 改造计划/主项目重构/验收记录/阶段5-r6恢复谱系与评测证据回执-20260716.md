# 阶段 5：r6 恢复谱系与评测证据回执验收（2026-07-16）

## 1. 定位与谱系边界

r6 是在 r5 临时产物被并发 `clean` 清除后，从仍存在的 3 个 Source、16 个已索引 chunk 语料及可用 raw 输入重新建立的评测谱系。r5 使用的旧 HMAC 盐遵守安全要求没有持久化，因此无法恢复相同的假名 ID、fingerprint、artifact digest，也不能 byte-for-byte 重建 r5 gold 或 shadow。

所以，r6 是新的 HMAC lineage，不是对 r5 artifact 的恢复。r5 验收记录继续作为 2026-07-15 当时的历史指标和测试截面；从本记录开始，当前可复验的离线 artifact lineage 由 r6 supersede。该 supersede 只替换当前 artifact 证据链，不把 r5 的历史数值改写成 r6，也不表示 production gate 已完成。

r6 dataset version 为：

`stage5-real-qa-r6-recovered-20260716-reviewed-sanitized`

数据集保持 8 个 case，其中 6 个可回答、2 个应拒答。人工审核仍只用于开发侧离线 gold；普通用户在线提问后直接看到回答正文和引用来源，不经过人工审核。

## 2. 五轮 compile 与漂移校验

r6 在同一新 lineage 下完成 5 轮 `compile-reviewed`。五轮均通过 raw HMAC fingerprint、candidate identity、顺序、score、Snapshot、正文及 candidate count 漂移校验，没有把脱敏后碰巧相同的输入误当成同一 raw 输入。

五轮结果：

- 5 份 sanitized gold 的 SHA-256 完全一致；
- 5 份 shadow 的完整 admitted ranking signature 只有 1 种；
- 8/8 case 均完成评测；
- 每轮均保持 6 个可回答、2 个拒答案例。

这些结果证明提供给 receipt 的 r6 artifacts 在内容摘要、聚合结果和完整 admitted ranking 上一致。它们不证明五份 shadow 一定来自五次相互独立的基础设施执行；独立执行性需要额外的运行 provenance、不可伪造执行 ID 或外部调度证据。

## 4. Content-free Evidence Receipt

r6 的持久化评测回执位于：

`evidence/阶段5-r6-recovered-receipt.json`

回执 schema 为 `retrieval-evaluation-evidence-receipt-v1`，当前 receipt 文件 SHA-256 为：

`96db0782e64c4877f34f081ea0233e134aa5b6139957452910f578f5438d21c5`

Receipt 只保留以下非正文证据：

- dataset version 与单一 `strategyProfile`；
- gold 和每份 shadow 的 byte size、SHA-256；
- 每份 snapshot version、case count、聚合质量指标与 runtime 指标；
- 每份完整 admitted ranking 的 SHA-256 signature；
- snapshot 数量、不同 ranking signature 数量及合并 latency。

Receipt 明确不包含文件路径、case/evidence/source/citation ID、query、candidate 正文或 HMAC 盐。它证明的是 receipt 生成时所读取 artifacts 的摘要、profile、聚合指标和 ranking signature 一致性；它不是数字签名、外部见证、时间戳认证或不可抵赖证明，也不证明 5 次执行彼此独立。

## 6. Production gate 状态

r6 与 evidence receipt 关闭的是“r5 临时 artifact 丢失后缺少当前可复验离线谱系”和“多份 sanitized artifact 缺少 content-free 摘要回执”的证据缺口。它们没有关闭阶段 5 production gate。

仍待完成：

- 从最终持久化 EvidenceBundle、execution trace 与 citation 导出的真实 online AnswerRun 样本；
- baseline/V2 各自的正式 profile-aware production quality policy 与阈值；
- Workspace 真实灰度、回切和尾延迟观测；
- faithfulness、answer relevance 与 cost 指标；
- 定时 benchmark、CI 四层评测编排与合并后 container smoke；
- 能证明多轮运行独立性的 execution provenance。

在这些门禁完成前，Workspace V2 技术开关保持默认关闭，r6 不作为生产阈值，也不据此引入 vector、RRF 或 rerank。

## 7. 用户与范围边界

本切片只处理开发侧离线评测 artifact 与 content-free receipt，没有修改前端，也没有读取或修改 `workers/research-worker/`、`workers/artifact-worker/`。Research/Artifact 仍只是 QA 数据集中的资料主题，不代表本切片进入两个独立 worker。
