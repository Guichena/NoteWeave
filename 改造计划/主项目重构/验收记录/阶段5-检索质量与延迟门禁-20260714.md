# 阶段 5 检索质量与延迟门禁验收

- 日期：2026-07-14
- 后端测试：168/168
- Policy schema：`retrieval-quality-gate-v1`
- 状态：版本化门禁机制、CLI、受控策略 fixture 和确定性测试已完成；生产阈值尚待真实 QA gold/shadow 校准

## 完成内容

- 新增 `RetrievalQualityGatePolicy`，策略显式绑定 schema version、policy version、dataset version、最小 case 数与全部阈值；
- 新增 `RetrievalQualityGate`，复用 `RetrievalShadowComparator` 的同一份 baseline/shadow 报告，不复制排名或质量计算；
- 绝对质量门禁覆盖 macro Recall@K、MRR、nDCG、citation precision/coverage 和 refusal accuracy；
- 相对质量门禁覆盖上述指标相对 deterministic BM25 baseline 的允许 delta；
- 稳定性与安全门禁覆盖 mean topK overlap、top1 changed ratio、scope violation count 和 p95 latency；
- 每个失败项输出 metric、operator、threshold 和 actual，结果包含 policy/dataset/snapshot version，可供 CI 留档；
- 策略与 comparison 的 dataset version 必须完全一致，避免跨 gold set 复用不可比阈值；
- 比例阈值限制在 `[0,1]`，delta 限制在 `[-1,1]`，case/count/latency 进行正数或非负校验；
- CLI 接受 gold、shadow、policy 三个 JSON 路径；门禁失败时先输出结构化结果，再返回失败状态。

## 受控策略 Fixture

- 新增 `stage5-quality-gate-policy-v1.json`，绑定 `stage5-fixture-20260714`；
- baseline 等价 shadow 满足全部阈值，验证绿色路径与稳定输出；
- 故意回退的 `stage5-shadow-fixture-v1.json` 会触发质量、delta、overlap、top1、scope 和 p95 violation；

- fixture policy 只验证门禁能力，不是根据真实 Elasticsearch 样本校准的生产阈值。
