# 阶段 6 Redis 分布式配额与租约验收

- 验收日期：2026-07-14
- 范围：Chat rate token bucket、Research/Artifact leased semaphore、本机保守降级、Task lease 生命周期、指标与 Docker 配置
- 状态：后端分布式 quota 切片完成；阶段 6 下一批进入前端模块化

## 1. Key 与原子算法

Quota 使用独立环境命名空间：

```text
noteweave:v1:quota:{environment}:rate:{workspaceId}:{actorFingerprint}:{workload}
noteweave:v1:quota:{environment}:concurrency:{workspaceId}:{workload}
```

- actor 使用 SHA-256 fingerprint，不写原始用户标识；
- workload 只允许 `chat/research/artifact` 等低基数值；
- token bucket 以 Redis Hash 保存 token 与 updated-at，单次 Lua 原子 refill、consume 和 TTL；
- semaphore 以 Redis ZSET 保存不透明 task token 与过期时间；acquire 原子清理过期成员、判断 limit、写 lease 和 TTL；
- strict renew 使用独立 Lua，仅允许续约仍存在的 token，不允许已过期 owner 重新抢占；
- release 以 token 精确 `ZREM`，不误删其他 owner。

## 2. 调用与事务边界

- `ChatService.sendMessage` 在写 User/Assistant Message 和 AnswerRun 前执行 rate check；
- `TaskService.createTask/redriveTask` 仅对 `RESEARCH_RUN/ARTIFACT_JOB` 执行 rate + lease acquire；Source parse 等内部任务不占长任务 quota；
- heartbeat、progress 和 waiting callback 严格 renew；完成与失败在事务提交后 release；
- create/redrive 后续数据库写失败时，事务 completion callback release 已获取的 lease；
- 重复终态 callback 不重复 release，迟到进度不能重新获得 lease。

## 3. Redis 故障降级

Redis bean 缺失或命令错误时回退进程内保守限制：

- 独立本机 token bucket；
- 本机 lease limit 默认小于分布式 limit；
- Redis 成功 acquire/renew 同步维护本机 shadow，运行中 Redis 故障仍可续约当前进程已知 lease；
- 本机 shadow 不提供跨实例共享语义，Redis 恢复后仍由 Redis lease 决定分布式准入；
- quota 可由 `NOTEWEAVE_QUOTA_ENABLED=false` 独立关闭，不影响 Streams/cache 开关。

## 4. 指标

以下 meter 只使用 control、workload、result、backend 等低基数 tag：

- `noteweave.quota.decisions`：granted/rejected/disabled/error 决策；
- `noteweave.quota.rejections`：rate/concurrency/renew 快速拒绝；
- `noteweave.quota.lease.recovered`：acquire/renew 清理的过期 lease 数。

生产容器重建后健康，真实 Chat 请求触发：

```text
control=rate
workload=chat
result=granted
backend=redis
```

Redis 中对应 key 位于 `noteweave:v1:quota:development:*`，未出现 integration 测试残留 key。

## 6. 回滚

紧急回滚设置 `NOTEWEAVE_QUOTA_ENABLED=false` 并重启 Backend；不会删除 Task、AnswerRun 或业务数据。Redis quota key 全部有 TTL，可按环境 namespace 定向清理，不应 flush Streams/cache。Redis 故障时默认保持 quota enabled，让本机保守上限继续生效。
