# 阶段 6 前端 Artifact 动态控制台边界验收

- 验收日期：2026-07-15
- 范围：Artifact rail JSX 抽取、动态 import、Studio/job/version/history 交互 props、架构门禁与 bundle 验证
- 状态：本批完成；聊天主面板与 Research 主报告/审计面板继续拆分

## 1. 真实组件边界

新增 `src/features/artifacts/ArtifactRail.tsx`，从 `App.tsx` 迁出完整 Artifact rail，而非创建空壳：

- Studio skill chooser 与 composer；
- 结构化 input、hint、聊天预填与异步生成；
- 正在生成任务与 wait context；
- latest version 的审计摘要、文件状态、资料保存、Note/Wiki writeback、regenerate、compare、rollback 与 PDF export；
- version history/detail；
- Wiki、Research、Memory 和保存最新回答为 Note 的工具入口。

组件通过显式 props 接收交互状态、回调、格式化 helper 与 `useArtifactState` 的投影。job/version/history/receipt 不在组件中重新建 state，仍由 Artifact feature hook 作为唯一 owner。

## 2. 动态加载与防回流

`App.tsx` 使用：

```tsx
const LazyArtifactRail = lazy(() => import("./features/artifacts/ArtifactRail")
  .then((module) => ({ default: module.ArtifactRail })));
```

并通过 `Suspense` 加载实际 rail 和轻量 loading fallback。

`ui-contract-check.mjs`：

- 禁止 App 回流 `<div className="artifact-composer-view">`；
- 要求 `LazyArtifactRail` 和真实 dynamic import；
- 读取 ArtifactRail 文件，确认“创建产物”“最新结果”“产物历史空态”“更多工具”和 Wiki/Memory 入口仍已接线。
