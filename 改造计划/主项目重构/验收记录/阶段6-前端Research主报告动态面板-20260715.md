## 1. 真实报告组件

新增 `src/features/research/ResearchReportPanel.tsx`，从 `App.tsx` 抽出完整主报告文章区：

- run metadata、恢复来源和报告刷新/导出/保存入口；
- Result Snapshot、executive summary、Research Report 与 markdown；
- Workspace Sources、evidence highlights、最终结论与闭环摘要；
- report save-as-source receipt、source scope 回流及加入/移出/定位动作；
- 时间线摘要。

组件通过显式 props 接收 `useResearchState` 的 current run、既有 Research read model、派生 summary 和页面工作流回调。它不创建新的 run、checkpoint、evidence 或 Memory 状态。

## 2. 动态加载与门禁

`App.tsx` 使用：

```tsx
const LazyResearchReportPanel = lazy(() => import("./features/research/ResearchReportPanel")
  .then((module) => ({ default: module.ResearchReportPanel })));
```

并以 `Suspense` 保留轻量报告加载 fallback。

`ui-contract-check.mjs`：

- 禁止 `<strong>Research Report</strong>` 正文回流 App；
- 要求 `LazyResearchReportPanel` 和真实 dynamic import；
- 读取报告组件，确认 Result Snapshot、Research Report、Workspace Sources、Writeback Receipt 和“保存为资料”入口仍已接线。
