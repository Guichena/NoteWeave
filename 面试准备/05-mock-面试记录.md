# NoteWeave Mock 面试记录

> 本文件为 2026-06-01 重构版，依据当前代码、测试和 Flyway 迁移整理。不要再按旧阶段计划或旧题库口径背。

## 0. 使用方式
每轮只练一个主问题。答完以后按“评价、不足点、改进口径、追问”复盘，并把薄弱标签写下来。

## 1. 当前建议优先练习模块
1. 项目总述：能否 2 分钟讲清双空间和闭环。
2. Task/Outbox/Kafka：能否讲清一致性、重试、取消。
3. Hybrid RAG/Citation：能否讲清证据链和防幻觉。
4. WebSocket/Memory：能否讲清 DRAFT/FORMAL 和 runtime state。
5. Artifact/Methodology/Synthesis：能否讲清生成结果不自动污染知识库。

## 2. 薄弱点标签
- 项目主述不清
- 场景不足
- 方案不具体
- 收益不明确
- 缺少权衡
- 证据锚点不足
- 抗追问弱
- 术语口径风险
- 模块边界混乱
- 把规划讲成已落地
