# NoteWeave 个人链路升级与竞品思考

> 本文件为 2026-06-01 重构版，依据当前代码、测试和 Flyway 迁移整理。不要再按旧阶段计划或旧题库口径背。

## 0. 本篇定位
本篇用于回答“为什么个人研究链路值得做”“它和普通笔记/RAG/NotebookLM 类产品有什么差异”。

## 1. 当前个人主链路
1. ResearchProject 定义个人研究上下文。
2. Source 支持 FILE、URL、TEXT 导入，并要求 READY 时有可读文本。
3. WikiCompilerService 抽 ArticleCard、ConceptCard、alias、relation。
4. EvidenceBacktraceService 把卡片证据回到 Source 原文。
5. PersonalGenerationService 基于卡片、证据和 Methodology 生成 Artifact。
6. 用户确认后 Artifact 通过 Distillation 变成 SynthesisCard。

## 2. 和普通 RAG 的差异
- 普通 RAG 偏“问一次答一次”，NoteWeave 个人侧偏“资料变结构化知识，再生成成果，再沉淀”。
- 普通笔记偏人工整理，NoteWeave 用 Source 编译和 evidence backtrace 降低整理成本。
- 普通生成工具容易污染知识库，NoteWeave 用 Artifact/Synthesis 的确认边界控制沉淀。

## 3. 可以讲的升级方向
- 更强的概念合并和低质量卡片清理。
- Bibtex/论文元数据作为 Source 类型扩展。
- 个人成果向团队 Wiki 的受控发布流程。
- 更细的 Methodology 推荐和生成质量评测。

## 4. 不能说满
- 当前不要说已经有自动论文发现和完整 Bibtex 主链路。
- 不要说个人研究会自动同步到团队知识库。
- 不要把 SynthesisCard 说成会自动重写 ConceptCard。
